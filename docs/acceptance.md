# 退货申请 Agent 验收案例

## 文档说明

本文件定义业务验收场景，作为实现检查和测试的依据。
预期结果应描述可观察的行为与数据变化，不限定代码实现方式。

## E01：合法的单件退货

### 1. 验证目标

验证满足退货条件时，Agent 能生成预览，并在用户明确确认后提交申请。

### 2. 初始条件

| 项目 | 值 |
|---|---|
| 当前调用身份 `current_user_id` | `"U001"` |
| 订单编号 `order_id` | `1001` |
| 订单行编号 `order_line_id` | `101` |
| 订单所属用户 `owner_id` | `"U001"` |
| 商品名称 `product_name` | `"蓝色 T 恤"` |
| 是否收货 `status` | `true` |
| 收货后天数 `days_since_delivery` | `3` |
| 购买数量 `purchased_qty` | `2` |
| 已占用退货数量 `reserved_qty` | `0` |
| 商品允许退货 `returnable` | `true` |
| 已有退货申请数量 | `0` |

本案例假设所需工具正常工作。

### 3. 用户操作

1. 用户输入：“我想退订单 1001 里的 1 件蓝色 T 恤，先看看能不能退。”
2. Agent 展示申请预览。
3. 用户输入：“确认提交。”

### 4. 预期结果

#### 4.1 展示预览后、用户确认前

- 展示的信息：能否退货、订单行编号、用户、退货数量、商品名称
- 退货申请记录数量：0
- `reserved_qty`：0
- 剩余可退数量：2
#### 4.2 用户确认并提交成功后

- 返回给用户的结果：“提交退货申请成功”
- 退货申请记录数量：1
- 申请内容：用户 “U001”、订单行 101、退货数量 1
- `reserved_qty`：1
- 剩余可退数量：1

### 5. 禁止行为

- 用户确认前，不得提交申请、新增申请记录或占用可退数量。
- 提交成功后，不得修改购买数量、订单归属、商品属性及其他订单行的数据。

## E02：申请数量超过剩余可退数量

### 1. 验证目标

验证申请数量超过剩余可退数量时，系统拒绝本次申请，说明原因，且不新增申请或改变已占用数量。

### 2. 初始条件

| 项目 | 值 |
|---|---|
| 当前调用身份 `current_user_id` | `"U001"` |
| 订单编号 `order_id` | `1001` |
| 订单行编号 `order_line_id` | `101` |
| 订单所属用户 `owner_id` | `"U001"` |
| 商品名称 `product_name` | `"蓝色 T 恤"` |
| 是否收货 `status` | `true` |
| 收货后天数 `days_since_delivery` | `3` |
| 购买数量 `purchased_qty` | `2` |
| 已占用退货数量 `reserved_qty` | `1` |
| 商品允许退货 `returnable` | `true` |
| 已有退货申请数量 | `1` |

本案例假设所需工具正常工作。

### 3. 用户操作

1. 用户输入：“我想退订单 1001 里的 2 件蓝色 T 恤，先看看能不能退。”
2. 用户输入：“确认提交。”

### 4. 预期结果

- 展示的信息：“本次申请 2 件，剩余可退 1 件，无法提交本次申请。”
- 退货申请记录数量：1
- `reserved_qty`：1
- 剩余可退数量：1

### 5. 禁止行为

- 可退货数量少于用户申请退货数量，无法创建申请
- 创建申请失败，购买数量、已占用退货数、已有退货申请数量都不发生改变

## E03：不能操作他人的订单

### 1. 验证目标

验证订单所属用户和当前调用身份不相同时，系统拒绝本次申请，说明原因，且不新增申请或改变已占用数量。

### 2. 初始条件

| 项目 | 值 |
|---|---|
| 当前调用身份 `current_user_id` | `"U001"` |
| 订单编号 `order_id` | `1001` |
| 订单行编号 `order_line_id` | `101` |
| 订单所属用户 `owner_id` | `"U002"` |
| 商品名称 `product_name` | `"蓝色 T 恤"` |
| 是否收货 `status` | `true` |
| 收货后天数 `days_since_delivery` | `3` |
| 购买数量 `purchased_qty` | `2` |
| 已占用退货数量 `reserved_qty` | `0` |
| 商品允许退货 `returnable` | `true` |
| 已有退货申请数量 | `0` |

本案例假设所需工具正常工作。

### 3. 用户操作

1. 用户输入：“我想退订单 1001 里的 1 件蓝色 T 恤，先看看能不能退。”
2. 用户输入：“确认提交。”

### 4. 预期结果

- 展示的信息：“无法查询或操作该订单，请核对订单信息。”
- 退货申请记录数量：0
- `reserved_qty`：0
- 剩余可退数量：2

### 5. 禁止行为

- 当前调用的用户没有处理对应订单的权限，无法创建申请
- 创建申请失败，购买数量、已占用退货数、已有退货申请数量都不发生改变
- 不得向当前用户披露或确认他人订单的归属、商品、数量等详情。
